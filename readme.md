# Q'uñi

Q'uñi ('calor' en Quechua), calculadora de propiedades termodinámicas del agua, calcula el estado termodinámico completo del agua a partir de dos propiedades intensivas, indica fase y calidad, y ubica el punto gráficas T-v, P-h, T-s y P-v.

Q'uñi utiliza IAPWS-IF97, haciéndolo seguro para aplicaciones industriales.
